SRASel

Within-host selection in viral time series

SRASel looks for directional frequency changes of viral variants across several samples of the same patient over time. The same scientific engine is available in three ways; pick the one that fits your data.

Experimental

Run in Browser

Runs the real SRASel stages (Python compiled to WebAssembly, Pyodide) inside your browser tab. Nothing to install, nothing uploaded.

It can be slower than the command line and can fail because of browser memory limits, especially with large inputs or many permutations.

BAM files or bam-readcount tables. BAM files are counted in the browser with pysam (same rules as bam-readcount -q 20 -b 20 -w 0, identical counts on the 47 real BAMs tested) and read in place, never uploaded; or load the <sample>_RG_readcount.txt tables, which is faster. A dates file and a GenBank reference are needed in both cases.

Your computer

Run with Local Python: web interface

A graphical interface served only on your own machine. It reads your BAM files where they are and runs the full pipeline with the native tools, so nothing leaves your computer.

git clone https://github.com/<USER>/SRASel.git && cd SRASel
conda env create -f environment.yml && conda activate srasel
srasel web

The conda environment installs samtools and bam-readcount, which are not Python packages; check them with srasel doctor. Then open the address that srasel web prints. Replace <USER> by the account that hosts the repository.

Recommended

Command line

The reference way to run SRASel: BAM files in, results out, several cores, resumable, suitable for clusters.

git clone https://github.com/<USER>/SRASel.git && cd SRASel
conda env create -f environment.yml
conda activate srasel
srasel doctor

SRASel is installed from the repository (it is not on PyPI). If conda reports a libmamba error, add --solver classic.

Example (samples.tsv has three tab-separated columns: BAM path, patient, sampling date):

srasel run --samples samples.tsv \
  --virus "Severe acute respiratory syndrome coronavirus 2" \
  --email you@example.org --out srasel_out \
  --threads 8 --nperm 2000 --seed 1

Results (tables, plots, report.html, SUMMARY.md) are written to srasel_out/. Use --ref-file my.gb instead of --virus to work offline with your own GenBank reference.

Which one should I use?

  • Real data, many samples, long jobs: command line.
  • You prefer buttons to options but have the BAM files on your computer: local web interface.
  • You only want to try the analysis, or you have a small data set (BAM files or bam-readcount tables) and nothing installed: browser.

All three run the same engine.
